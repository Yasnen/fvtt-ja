# fvtt-ja
Foundry Virtual Tabletop 日本語翻訳（MRyas私家版）

インストール：FoundryVTTの設定とセットアップで、アドオンモジュールのモジュールインストールから「fvtt-ja」を検索してインストールしてください。以下のマニフェスト URL を指定してインストールすることも可能です。

```
https://raw.githubusercontent.com/Yasnen/fvtt-ja/main/module.json
```

## 使用にあたってのお願い
本モジュールはMRyasがWFRP4eシステムをFVTTで遊ぶために作成した私家版です。FVTT上での使用には制限しませんので、ご自由にお使いください。その他の使用（ソースコードの流用など）については現状では許可しません。

# 追加機能
## 独自言語ファイル
「言語ファイルフォルダ」を設定すると、そのフォルダに置いた独自の JSON ファイルをモジュール・システムの言語ファイルとして読み込みます。フラット方式とサブフォルダ方式（バージョン管理）に対応しています。詳細は [docs/lang-folder.md](docs/lang-folder.md) を参照してください。

## デフォルト言語設定チェック
本モジュールはFVTT本体のデフォルト言語として使われている前提で作成しています、ゲームシステム起動時に警告メッセージが出た場合、FVTT本体設定のデフォルト言語を「日本語-日本語：FVTT（MRyas私家版）」に設定してください。

## ジャーナル翻訳機能

**前提：Babele モジュールが有効な場合のみ動作します。**

Babele のコンバータ `fvttJaJournalPages` を使ってジャーナルエントリのページを翻訳する機能です。リンクラベルの日本語化・二言語表示・ソース更新検出・翻訳テンプレートのエクスポートに対応しています。

| 設定名 | デフォルト |
|--------|---------|
| 二言語ジャーナル表示 | 無効 |
| ソース更新チェック | 有効 |

翻訳テンプレートはコンソールで `await FVTTJa_collectJournals()` → `FVTTJa_exportJournals()` を実行してエクスポートできます。詳細は [docs/journal.md](docs/journal.md) を参照してください。
