# モジュール設定翻訳

## 概要

i18n に対応していないモジュールの設定画面（名前・ヒント・ラベル）を  
JSON ファイルで上書きしてローカライズする機能です。

設定画面の「モジュール設定翻訳：追加ファイル」にファイルを指定すると、  
組み込みデータと追加ファイルをマージして適用します。

---

## 組み込みデータ

`lang/module-setting-overrides.json` に配置します。

このファイルは fvtt-ja モジュールに同梱されており、書き方のサンプルを兼ねています。  
利用者は直接編集せず、後述の「追加ファイル」で補完・上書きしてください。

```json
{
  "image-hover": {
    "permissionOnHover": {
      "name": {
        "original": "Required actor permission",
        "translation": "アクターの必要権限"
      },
      "hint": {
        "original": "Required permission level of Actor to see handout.",
        "translation": "ハンドアウトを表示するために必要なアクターの権限レベル。"
      }
    }
  }
}
```

---

## 追加ファイル

設定画面の「**モジュール設定翻訳：追加ファイル**」にファイルパスを指定します。  
組み込みデータにないモジュールを追加したり、組み込みの翻訳を上書きできます。

---

## JSON フォーマット

```json
{
  "モジュールID": {
    "設定キー": {
      "name": {
        "original": "原文（英語）",
        "translation": "翻訳文（日本語）"
      },
      "hint": {
        "original": "原文（英語）",
        "translation": "翻訳文（日本語）"
      }
    }
  }
}
```

### フィールド

| フィールド | 対象 | 省略 |
|---|---|---|
| `name` | 設定項目の表示名 | 可 |
| `hint` | 設定項目の説明文 | 可 |
| `label` | 設定メニューのボタンラベル | 可（メニュー項目のみ） |

各フィールドは `original` と `translation` のペアで記述します。  
`translation` が空文字の場合はその項目を翻訳せずスキップします。

---

## テンプレートの生成

FVTT ブラウザのコンソールで以下を実行すると、現在有効なモジュールの  
未翻訳設定を一括スキャンしてテンプレート JSON をダウンロードできます。

```js
FvttJa.generateSettingOverrideTemplate()
```

**スキャン対象：**
- アクティブなモジュールの通常設定（`name`・`hint`）
- 設定メニュー（`name`・`hint`・`label`）

**スキャン除外：**
- 既に組み込みデータまたは追加ファイルにエントリが存在するもの
- `config: false`（設定画面に表示されない隠し設定）
- 原文が非 ASCII 文字を含む（既に翻訳済みと判断）
- `game.i18n.localize()` で解決できるもの（i18n 対応済み）

生成されたファイルの `translation` を埋めて追加ファイルに指定してください。

---

## 原文変更時の動作

モジュール更新などで設定項目の原文が変わった場合、`original` との不一致が生じます。  
その際の動作は設定画面の「**モジュール設定翻訳：変更時動作**」で選択できます。

| 設定値 | 動作 |
|---|---|
| 原文を表示（既定） | 翻訳を適用せず原文のまま表示。コンソールに警告を出力する。 |
| 翻訳を適用 | 原文変更を無視して翻訳を強制適用する。 |

---

## 適用優先順位

同じキーが複数のソースに存在する場合、後から読み込まれたものが優先されます。

```
組み込みデータ (lang/module-setting-overrides.json)
    ↓ 追加ファイルで上書き可能
追加ファイル (settingOverrideUserFile)
    ↓
設定画面へ適用
```
