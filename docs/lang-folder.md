# 独自言語ファイルフォルダ 構造・管理ガイド

## 概要

「言語ファイルフォルダ」を設定すると、そのフォルダに置いた独自の JSON ファイルが  
モジュール・システムの言語ファイルとして読み込まれます。

ファイルの配置方法は **フラット方式** と **サブフォルダ方式** の2種類があります。

---

## フラット方式（シンプル）

```
<言語ファイルフォルダ>/
├── babele.json
├── babele-ja.json
├── dnd5e.json
└── dnd5e-ja.json
```

### ファイル命名規則

| ファイル名 | 対象 |
|---|---|
| `{モジュールID}-ja.json` | 対象モジュール |
| `{システムID}-ja.json` | ゲームシステム |

`-ja` は必須です。バージョン管理が不要な場合はこちらを使用してください。

---

## サブフォルダ方式（バージョン管理あり）

モジュールIDと同名のサブフォルダを作成し、その中にファイルを置きます。

```
<言語ファイルフォルダ>/
├── babele/                        ← モジュールID名のサブフォルダ
│   ├── ja.json                    ← 省略形・フォールバック
│   ├── ja-1.0.0.json              ← 省略形・バージョン指定
│   ├── ja-2.4.0.json
│   └── babele-ja-3.0.0.json       ← ID 付き形式も可
└── dnd5e/
    ├── dnd5e-ja.json              ← ID 付き形式・フォールバック
    ├── dnd5e-ja-3.2.0.json        ← ID 付き形式・バージョン指定
    └── ja-3.3.1.json              ← 省略形との混在も可
```

### ファイル命名規則

サブフォルダ名にモジュールIDが含まれているため、ファイル名の **モジュールID は省略可能** です。  
翻訳ファイルには **`-ja` が必須** です（`-ja` のないファイルは読み込まれません）。

| ファイル名 | ID省略 | バージョン指定 | 用途 |
|---|---|---|---|
| `{ID}-ja.json` | 不可 | なし | フォールバック |
| `{ID}-ja-{ver}.json` | 不可 | あり | バージョン指定ファイル |
| `ja.json` | **省略形** | なし | フォールバック |
| `ja-{ver}.json` | **省略形** | あり | バージョン指定ファイル |

- `{ver}` は `1.0`、`3.2.1`、`13.351` のように **数字とドットのみ** で構成します（桁数は任意）。
- ファイル名の `{ver}` に **`v` 接頭辞・プレリリース表記（`-beta` 等）・ビルドメタデータ（`+build` 等）は使用できません**。これらを含むファイル名はバージョン指定として認識されず、フォールバック扱いになります。
- ID 付き形式と省略形は混在できます。

#### 照合対象（モジュール側のバージョン）について

選択の基準となるのは、対象モジュール・システムが `module.json` / `system.json` で宣言している実バージョンです。
このバージョンが `"v9.2.0"` のように **先頭に `v` を含む** 場合でも、内部で `v` を除去して数値比較するため、ファイル名側は `v` なし（例: `{ID}-ja-9.2.0.json`）で記述してください。

---

## バージョン選択ロジック

サブフォルダ内に複数ファイルがある場合、モジュール・システムの **実際のバージョン** を基準に次の順序でファイルを選択します。

```
1. 完全一致するバージョンのファイルがあれば使用
       ↓ なければ
2. 実バージョン以下で最も高いバージョンのファイルを使用
       ↓ なければ（全ファイルが実バージョン超過）
3. バージョン付きファイルの中で最も低いバージョンのファイルを使用
       ↓ バージョン付きファイルが存在しない場合のみ
4. バージョン指定なしのファイルを使用
```

### 選択例

モジュールの実バージョンが `2.5.0` のとき：

| フォルダ内のファイル | 選択されるファイル | 理由 |
|---|---|---|
| `mod-2.5.0.json` のみ | `mod-2.5.0.json` | ①完全一致 |
| `mod-2.4.0.json`, `mod-3.0.0.json` | `mod-2.4.0.json` | ②以下で最も高い |
| `mod-3.0.0.json`, `mod-4.0.0.json` | `mod-3.0.0.json` | ③超過の中で最小 |
| `mod.json` のみ | `mod.json` | ④バージョン指定なし |
| `mod.json`, `mod-2.4.0.json` | `mod-2.4.0.json` | ②バージョン付きを優先 |

## フラット方式とサブフォルダ方式の併用

同一フォルダにフラット方式とサブフォルダ方式が混在しても構いません。  
同じモジュールIDに対してサブフォルダが存在する場合、**サブフォルダ方式が優先**されます。

```
<言語ファイルフォルダ>/
├── babele.json          ← サブフォルダ babele/ がない場合のみ使用
├── babele/              ← こちらが優先
│   ├── babele.json
│   └── babele-2.4.0.json
└── my-module.json       ← フラット方式（サブフォルダなし）
```

## 言語ファイル追加機能（オプション）

FVTT 設定で「言語ファイル追加機能」を有効にすると、モジュール更新などで新しい翻訳キーが追加された際に自動検出し、元ファイルを参照用として複製します。

### 動作条件（両方を満たす場合に実行）

1. サブフォルダ内に **モジュールの現バージョンと完全一致するファイルが存在しない**
2. モジュールの元の言語ファイルに、**選択されているファイルにないキーが存在する**

### 複製ファイルの命名

```
{元の英語ファイル名（拡張子なし）}-{バージョン}-en.json
```

元のファイル名を保持したまま、バージョンと `-en` を付与します。

| 英語元ファイル | 複製先ファイル名（v3.0.0 の場合） |
|---|---|
| `en.json` | `en-3.0.0-en.json` |
| `en-compendium.json` | `en-compendium-3.0.0-en.json` |

英語ファイルが複数ある場合はそれぞれ個別に複製されます。

### 動作フロー例

```
babele/
├── ja-2.4.0.json             ← 現在使用中（v3.0.0 に完全一致なし）
├── en-3.0.0-en.json          ← 自動複製（babele v3.0.0 の英語元ファイル）
└── en-compendium-3.0.0-en.json  ← 英語元ファイルが複数ある場合
```

→ `-en.json` ファイルを参照して差分キーを翻訳し、`ja-3.0.0.json` として保存することで次回から完全一致ファイルが使用されます。

### 注意事項

- `-en.json` で終わるファイルは **言語ファイルとして読み込まれません**（参照用のみ）
- 同名の `-en.json` が既に存在する場合は上書きしません
- キー比較はネスト構造を含む **全葉キー** を対象とします
- 複製実行後、次回ロード時にファイル変更検知ダイアログが表示されます

---

## 注意事項

- フォルダの走査は **1段階のみ**（サブフォルダのさらに下は対象外）
- サブフォルダ名は対象モジュールまたはシステムの **ID と完全一致** させてください
- ファイル変更を検知した場合、FVTT のリロードを促すダイアログが表示されます
- `init` フック時点でファイルパスを言語ファイルとして登録するため、変更後は必ずリロードが必要です
